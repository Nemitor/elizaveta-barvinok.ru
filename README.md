# Сайт-портфолио Елизаветы Барвинок

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт и публикует его при каждом push в ветку `main`.

На GitHub Free репозиторий для Pages должен быть публичным.

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. В настройках DNS домена `elizaveta-barvinok.ru` укажите A-записи GitHub Pages:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
4. После первого успешного workflow проверьте домен в **Settings → Pages** и включите **Enforce HTTPS**, когда сертификат будет готов.

`public/CNAME` связывает публикацию с доменом. Скрипт `scripts/prepare-pages.mjs` добавляет статические входные страницы для URL проектов, поэтому их можно открывать напрямую и обновлять без ошибки 404.

Для локальной проверки выполните `npm ci`, затем `npm run build`. Готовый сайт появится в `dist/`.
